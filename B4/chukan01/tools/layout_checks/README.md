# 図表の配置とPDF検査

| 規則 | 判定内容 |
|---|---|
| R1 必須 | 片段の図表は段上端から連続するグループに置く．図表間に通常本文を挟まない． |
| R2 必須 | 本文の最初の参照が図表本体とキャプション全体より先に読めること．読順はページ，左段・右段，段内の上から下の順とする． |
| R3 必須 | キャプションと図表本体を所属段の横幅および本文領域の上下端に収める． |
| R4 必須 | キャプションと図表本体が同じ段で対応し，間が不自然に離れないこと． |
| R5 推奨 | 初出参照の直後に利用できる段上端へ置く．直後の段で高さが足りない場合は次の段へ送る．2段以上離れ，途中の段に収まらなかったと座標から見積もれない場合は目視で確認する． |
| R6 推奨 | 参照から2ページ以上先へ送らない． |
| R7 必須 | 同一グループの同種の図表は本文の初出参照順に置く． |
| R8 推奨 | 図表グループを `\topfraction` 以内に収め，本文用に段高の25%以上を確保する． |
| R9 推奨 | 混在するグループでは図を表より上に置く．初出参照後の配置と段内への収まりを優先し，表より下の図は警告して目視確認する． |

本文の初出参照より後に，ラベル付きの `figure[t]` または `table[t]` を記述する．この原稿では必要な箇所で `\suppressfloats[t]` を使い，段上端と段全体の浮動体数の上限を各100，`\topfraction` を0.67，`\textfraction` を0.25とする．参照順と容量はビルド後のPDFで検査する．

リポジトリの中間発表原稿ディレクトリで，保護・用語検査に合格してビルドした後に実行する．

    python -B tools/layout_checks/check_float_placement.py
    python -B -m unittest discover -s tools/layout_checks -p "test_*.py"

既定ではビルド先の `main.pdf`，同時に生成された `main.aux`，および `main.tex` を照合する．別のPDFと対応するビルド情報を使うには `PDF --aux AUX --tex TEX` を引数に指定する．この独立検査には `pypdf` と Poppler の `pdftotext` が必要で，OCRは使用しない．統合チェッカーやLaTeXビルドからは独立して実行する．

PDFの名前付きリンク先と `.aux` の番号からキャプションを同定し，本文の初出は対応するPDFリンクの座標から取得する．図はキャプション直上の同じ段にある単一のPDF画像矩形を本体とし，表は罫線と行内の文字座標から本体を見積もる．現行A4設定の本文上端は20 mm（56.69 pt），左右余白は各15 mm，段間は16.82 ptである．段上端の許容差は8 pt，段幅は1 pt，キャプションと本体の間隔は12 ptとする．

初ページは全幅の題目・要旨の下から本文の左右段が始まる．PDFの `Doc-Start` と第1節のリンク先が初ページの同じ高さを示す場合は，その位置を初ページの段上端とする．

段上端から図表を読み順にたどり，図表の間に同じ段の文字がないこと，空きが26 PDF pt以内であることを調べる．クラスの `\floatsep` は10.96 TeX pt（伸縮あり）である．各グループの内訳・上下端・高さ・本文に残る段高を出力する．本文の残りは下端からグループの終端と `\textfloatsep` 相当の18 PDF ptを引いた見積もりである．次段に送られた図表の収容量を推定する際は，LaTeXと同様に最初の浮動体に対する `\textfloatsep` も見込む．実際の本文量や配置待ち順までは再現しない．

終了コードは，必須条件を全件確認できた場合に `0`，必須違反または表・参照の個別判定不能があれば `1`，入力不整合や実行不能は `2`．`WARN` は必須条件を満たしたうえで推奨条件に再確認が必要な表を示す．

全幅図表，浮動体専用ページ，罫線のない表，ベクトル描画や複数画像を含む図など，本体を一意に同定できない場合は自動検査を不合格または検査不能とし，目視確認が必要となる．例外を提案する場合はこの文書に図表ラベル，対象規則，理由，PDF上の位置を記録し，ユーザーの判断を求める．
